    Tips

    • Put each L-TEK Prime in its Dancepad profile: the Start/Select buttons glow green + red.
    • Stepping on the left pad lights up Player 2? Press Swap P1 ⇄ P2.
    • Wrong panel lighting up? Note which raw button number lights when you step on it, and fix the mapping in src/lib/pads.ts.
    • Hold SELECT (or Esc) for a second to go back to the menu.
    • Keyboard: P1 is ←↑↓→ or WASD, Start Enter/E, Select Esc/Q. P2 is IJKL, Start O, Select U.
